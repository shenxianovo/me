# 往后

## 工作

本科毕业后我想做软件研发，方向是后端、AI Infra、研发工具和可观测性。我想做真能用的系统，不想只为了秀技术写东西。上班赚钱和业余写软件，对我是两码事：上班首先是为了赚钱，自己写项目是因为喜欢、好玩、想做点东西，没想靠它攒能力或者攒钱。

选第一份正式工作，我主要看薪资、团队自主权和工作强度。这三样没有绝对的先后，也不是工资高就什么都不管了。我会给它们各自一个权重，看具体机会综合掂量，不会只拿一个指标判断值不值得去。权重具体多少，我还没定。

工作强度不只看一天干几个小时，也看时间和干活的方式能不能自己掌握。「偶尔加班，但时间灵活、没那么多没用的会和催进度」和「严格朝九晚六，但过程管得很细」，让我选的话我选前者。我喜欢能自己定节奏、能专心干活的地方。

城市我不挑，机会合适哪都行。比较确定的一点是不想去北京。除了北京，我不会因为城市本身去选或者不选一份工作。

大厂还是创业公司、小团队，我说不上偏好哪个。大厂里也可能有像创业公司的团队，我在 B 站花生就是这种感觉：组织挺扁，鼓励跨角色讨论，也鼓励试 AI Native 的做法。所以公司大小和名头，说明不了我最在意的自主权和氛围。可一个团队平时到底怎么干活，没进去之前一般不知道，面试也很难问出来：就算问了团队怎么协作、技术怎么拍板、AI 用得怎么样，对方的回答也未必是平时真实的样子。很多事只有进去干了才知道，所以选工作时，团队氛围这块我心里始终没底。

最近把「团队自主权」想得更清楚了一点。我想要的不只是自己写代码、选工具的自由，而是能对一项工作从设计到上线承担比较完整的责任，直接参与技术决策，甚至改变团队做事的方式。比如 CI、测试、发布、研发工具、跨角色协作这些流程，如果发现不合理，我希望有空间提出方案、验证并推动改进，而不是只能在既定流程里把自己那部分做快一点。

我觉得「组织可塑性」（Organizational Malleability）是个挺贴切的说法：一个普通工程师觉得现在的工作方式不合理时，究竟能在多大程度上改变它。这不等于想怎么干就怎么干，也不是希望把所有权力抓到自己手里。我更在意决策权和结果责任能不能匹配：一些高度耦合的环节放在同一条责任链里，可能比跨好几个部门反复交接更高效；但集中必要的决策权，不等于所有执行也非得由一个人包办。对我来说，能参与定义「怎样工作才更高效」，比只被允许在现有流程中高效工作更有吸引力。这种想法不只是找工作时才有的。之前在漫协当演音部长，我就因为一次很差的演出体验，重新划过晚会组织的责任边界；具体经历记在 [whudays.md](experience/whudays.md)。

## 为什么不读研

我打算本科毕业直接工作，不读研。想早点赚钱是一方面，更主要的是我很不看好再读三年的回报。

我觉得现在很多研究生最后都在「水论文」：几年时间搭进去，不一定做出了有用的东西。尤其是我感兴趣的 AI，前沿模型和 Agent 工程实践主要是业界在往前推，比我在学校里接触到的学术和教学快了一截。与其读研追论文和学历，我更想早点进真实的研发环境，直接 build some stuff。

## 关于价值和自由

我不觉得人生一定需要什么宏大的目标，也不觉得一个人的价值必须由社会贡献、收入或别人的认可来证明。

我想做自己感兴趣的事。哪怕做出来的东西没有什么外部回报，创造和体验的过程本身也可以有意义。比如最近想做的那个随身语音 Agent 设备，就算最后只有我一个人用，只要我每天都觉得它很好玩，我就觉得值得。做东西这件事，我在 [life.md](life.md#做东西) 里也写过。

我愿意为了自由去工作、赚钱，但更希望日常生活就有足够的自主权。我不想把所有值得期待的东西都推迟到以后。

我也不想一直往上爬、追职位和头衔。如果让我选：一种是为了早点退休，之前十几年高强度工作；另一种是可能一直工作到 60 岁，但每天只工作四五个小时，收入足够生活，剩余时间自己安排。我会选第二种。比起非得在某个年龄退休，我更在意生活中的时间能不能一直由自己支配。如果有收入够生活、时间又能自己安排的工作，我也愿意一直做下去。

如果有一天，我能自己决定怎么安排时间，不必为了生存去做自己不愿意做的事，那即使每天只是写点软件、造点小东西、打打游戏，我也会觉得这样的生活挺好了。

## 退休以后

退休以后干什么，我不想把日子排满。到那时 AI 应该比现在强很多。我可能还接着做自己的小项目，比如 Orisumi，把自己数字化这件事到时候也许做成了，也许没有。有新点子就自己或者跟 AI 一起写点软件玩，剩下的时间玩 VRChat，想干嘛干嘛。大概率还是宅在家，也没打算到处旅游。我想要的是不用再为了上班去安排自己的生活，倒不是从此什么都不干。
