# 高考后：第一台电脑和单片机

## 第一台电脑

2023 年高考完的暑假，我才有了第一台自己的电脑，小学那台是家里的。联想拯救者 Y7000P，Intel Core i7 处理器，NVIDIA GeForce RTX 4060 Laptop GPU。要打游戏也要编程，所以得有独显和够用的 CPU，型号是看 B 站的选购教程挑的。到 2026 年 10 月还在用。

以后可能再买台 MacBook，Windows 也留着：Windows 打游戏，Mac 写代码。写代码我更想要类 UNIX 环境，尤其用 Coding Agent 时，我觉得 Bash 比 PowerShell（pwsh）更好让 Agent 操作。Windows 上装了 WSL，用着还是别扭。可 Windows 程序的开发和验证又离不开 Windows，所以两边都要。

## 从单片机开始

高中毕业的暑假突然闲下来，没事干，就在 B 站找了套单片机教程，学 C 语言和 51 单片机，用的是 STC89C52RC。小学的 Flash 不算，这次才是正经开始编程。

大一上接着玩硬件，玩过 ESP32 和 STM32F103C8T6。学完 C 学 C++，碰了一下 Qt。我学编程没什么职业规划，就是看教程、写程序、折腾硬件，一路过来的。

后来单片机玩了一阵，转去学 C++ / Qt；Qt 学了点，又转去学 C#，结果 C# 一直用到现在。

嵌入式现在不做了，但单片机学到的还在。我知道 ESP32 为什么总被拿来做便宜的联网硬件：成本低，自带 Wi-Fi 和蓝牙。懂一些 GPIO、时序之类的底层控制，知道用 C 或 MicroPython 开发、在 IDE 里写完烧录的流程，也大概知道一块板子怎么做出来：用嘉立创的工具画 PCB、打板，买元件，焊接，烧固件。我自己会焊，贴片元件也能焊。

后来在 X 上看到有人拿 ESP32 接个 LLM API，就包装成新奇的「AI 硬件」宣传。我一眼就看得出它是怎么做的，这种包装唬不住我。
