# OpenWHU

## 先是贡献者

最早是自己想找课程资料，才发现了武大的开源课程资料库 [OpenWHU](https://github.com/openwhu/OpenWHU)。项目不是我建的，一开始也没想去管它。我先是用的人，顺手交点资料：2023 年 11 月交了 [#107「添加社会主义发展史」](https://github.com/openwhu/OpenWHU/pull/107)，2024 年 6 月交了 [#119](https://github.com/openwhu/OpenWHU/pull/119)，里面有工程制图（水利类）、高等数学等课的试卷。后来又补过几次，比如 [2025 年 2 月的 #135](https://github.com/openwhu/OpenWHU/pull/135) 和 [5 月 8 日的 #136《软件构造基础》资料更新](https://github.com/openwhu/OpenWHU/pull/136)。当了一阵普通贡献者，后来才开始考虑维护的事。

## 当上 Owner

2025 年 5 月，原维护者在 [#136 的讨论](https://github.com/openwhu/OpenWHU/pull/136)里让我发邮件联系他。聊下来，OpenWHU 当时差不多没人管了，之前想交给 WHUCAO 社区，也没落实。他问我想当 member 还是 maintainer，对社区有什么想法。

我说，武大校内分享学习资料的群和社区其实不少，自强淘课啦、WHUCAO、动漫社学习群都是，可它们互相不通，知道的人也不多。OpenWHU 自己宣传也不够，冷门专业的资料不全。我学过水利，对这点感受很深，当时就找不到什么水利专业课的资料。我希望它能借别的组织让更多人知道，同时保持独立。知道的人多了，来贡献的人才会多。

角色的话，我说可以的话就当 maintainer，理由很朴素：「本人比较闲的没事干（）」。结果他直接把我提成了 Owner，希望我让 OpenWHU 重新活起来。

## 实际做了什么

之后我接着交资料，也开始审、合别人的 PR，比如 [#138](https://github.com/openwhu/OpenWHU/pull/138)、[#140](https://github.com/openwhu/OpenWHU/pull/140)、[#148](https://github.com/openwhu/OpenWHU/pull/148)，到 2026 年的 [#166](https://github.com/openwhu/OpenWHU/pull/166)，都有我的 Review。有时就是谢谢贡献、合进去；有时会提醒对方把 README 写清楚，说明压缩包里到底装了什么。维护这个仓库，很大一部分就是让愿意分享的人能接着分享，让后来找资料的人好找、看得懂。

不过当上 Owner 以后，我干得最多的还是审 PR、合 PR、维护已有的资料，一开始想的大规模宣传和社区建设没怎么做。我在漫协学习群里宣传过，可群里学计算机相关专业的人不多。我观察下来，除了计算机、电信这类技术专业，别的专业的同学大多不用 GitHub，资料放在 GitHub 仓库里，很难传到他们那儿。「知道的人多，贡献的人才多」这个想法我还有，只是精力基本都花在了 PR Review 上。

OpenWHU 以前有过专门的资料下载站，是前一位学长用他读研课题组的机器搭的。学长毕业，下载站也就没了。我想过重新给普通学生做个下载入口，还在自己服务器上试过，但很快碰到现实问题：服务器带宽不够，国内云服务的带宽我又觉得太贵，就没再做。对不习惯 GitHub 的同学来说，有个下载站方便得多，可要让它一直稳定跑着，就得有人长期掏服务器和带宽的钱。

## 现状

现在 OpenWHU 就维持现状：有人交资料，我就审、就合，让仓库正常运转，不打算再花大力气扩张社区。以后碰到合适又愿意接手的人，就把维护权交出去。
